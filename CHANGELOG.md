# Changelog

## [1.5.0] - 2026-11-16

### Добавлено
- Интеграция отдельного ESP32-контроллера вентиляции: режим, заданный процент мощности, температуры, тревоги и настройки.
- Раздельное обнаружение и сохранение адресов старого датчика АТС и вентиляции.
- Наружная температура и сезонные предупреждения используют DS18B20 контроллера вентиляции.
- Индикация вентиляции в мини-гаджете. Процент отражает команду, не измеренные обороты.

### Исправлено
- Сборка использует проверенные OpenCV 4.13 и NumPy 2.4; устранено отсутствие кадров RTSP в первоначальном тестовом EXE на OpenCV 4.11.
- Полный просмотр камеры учитывает масштаб Windows без обрезания кадра.
- Переподключение RTSP, очистка устаревшего кадра и один цикл отрисовки при переключении камеры.
- Некорректные и устаревшие показания не останавливают опрос датчика.
- Запись БД и чтение истории выполняются вне потока интерфейса; пропуски данных отображаются корректно.
- Запись БД восстанавливается при последующих попытках после ошибки подключения; события ожидают занятую запись в очереди.
- Обновлятор защищает локальную конфигурацию БД/камер; адрес старого ESP хранится рядом с EXE.
- Звуковое уведомление использует поставляемый файл alert.wav.

### Примечания
- Релиз приложения не содержит прошивку ESP32 и не исправляет подтверждённые сетевые отвалы в тестовой сети.
- Настройки и алгоритм вентиляции остаются на контроллере.


## [1.4.2] - 2026-10-20

### Исправлено
- Updater теперь запускается из временной папки, а не из каталога программы: обновление может заменить и основной EXE, и updater.exe.
- Updater ожидает завершение конкретного PID приложения вместо ненадёжного поиска всех процессов по имени.
- Локальные файлы `openweather_api_key.txt` и `esp_last_ip.txt` сохраняются при обновлении.

## [1.4.1] - 2026-10-20

### Изменено
- Погода переведена с недоступного без VPN Open-Meteo на OpenWeatherMap.
- Ключ OpenWeatherMap читается из локального `openweather_api_key.txt` рядом с EXE и не включается в сборку или обновления.
- Запрос погоды выполняется в существующем фоновом потоке с тайм-аутом 8 секунд.

## [1.4.0] - 2026-06-03

### Добавлено
- Кнопка `🌐 Веб ESP` в верхней панели.
- Кнопка открывает веб-страницу текущей ESP в браузере по адресу `http://IP_ESP/`.
- Если ESP ещё не выбрана, программа подсказывает сначала найти устройство в сети.

### Изменено
- Версия приложения обновлена до `1.4.0` для проверки OTA-обновления через GitHub Releases.

## [1.2.0] - 2026-06-03

## [1.1.0] - 2026-06-01

### Добавлено
- Файл `VERSION` с текущей версией проекта.
- Файл `CHANGELOG.md` с историей изменений.

### Изменено
- Ускорен поиск ESP: сначала проверяется последний сохранённый IP, `ats-room.local`, `ats_room.local` и известный адрес `192.168.88.30`, затем подсеть сканируется параллельно.
- Переделано окно поиска ESP: ручной ввод IP, прогресс, статус проверки адресов, выбор найденного устройства.
- Конфиг `esp_last_ip.txt` теперь хранится рядом с программой.
- Запросы к ESP стали устойчивее: `Connection: close`, проверка структуры JSON, общий `set_esp_ip()`.

### Исправлено
- Ошибка `self.cam_label` при открытии окна камеры без подключённой камеры.
- Запуск программы больше не должен полностью падать при недоступной PostgreSQL БД.
- Логирование в БД защищено от исключений.
- Чтение значений ESP стало устойчивее к неполному JSON.
