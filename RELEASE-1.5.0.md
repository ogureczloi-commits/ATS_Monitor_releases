# ATS Monitor 1.5.0

Версия 1.5.0 добавляет управление отдельным контроллером вентиляции ESP32 и сохраняет мониторинг существующего датчика АТС.

## Установка

1. Распакуйте весь ZIP в отдельную папку. Сохраняйте ats_monitor_ui.exe, updater.exe и папку _internal вместе.
2. Для обновления существующей установки сначала сохраните копию её папки и завершите программу через «Выход» в трее.
3. Локальный ats_monitor_local_config.json с параметрами БД и камер хранится рядом с EXE и не входит в релиз. Для новой установки используйте ats_monitor_local_config.example.json как образец; заполните его и сохраните под именем ats_monitor_local_config.json.
4. Старый адрес датчика хранится в esp_last_ip.txt рядом с EXE. Если в прежней установке он был в _internal/esp_last_ip.txt, до обновления скопируйте его рядом с EXE или после установки выберите датчик заново.
5. Адрес вентиляции хранится в %LOCALAPPDATA%/ATS_Monitor/fan_endpoint.txt. При обновлении на том же Windows-пользователе он сохраняется.
6. Запустите ats_monitor_ui.exe. Настройки вентиляции загружаются из ESP32. Подключение к ней не требует прошивки.

## Что изменилось

- Режим, заданная мощность, датчики, тревоги и настройки отдельной ESP32 вентиляции.
- Наружная температура DS18B20 используется для сезонных уведомлений; мини-гаджет показывает вентиляцию.
- Фоновые запросы и ограничение актуальности данных.
- Полный просмотр камеры без двойного DPI-масштабирования; восстановление RTSP после обрыва.
- Фоновые операции БД и история с пропусками показаний.
- Защита локальных настроек обновлятором; исправлены пути состояния и звукового уведомления.

## Обновление

Для перехода через встроенное обновление требуется рабочий updater версии 1.4.2. В GitHub Release должен быть один Windows ZIP приложения; архив исходников не следует добавлять как второй ZIP-asset, так как старые клиенты выбирают ZIP по имени. Рекомендуемый тег: v1.5.0.

Прошивка ESP32 не входит в пакет. Процент мощности означает команду контроллера, а не измеренные обороты. Наблюдавшиеся в тестовой Wi-Fi-сети отвалы этим релизом не объявляются исправленными. Приложение не заменяет автономную защиту помещения от перегрева.

## Сборка из исходников

Python 3.12 x64; зависимости перечислены в requirements-build-py312.txt. Установленный Tcl/Tk должен быть доступен сборщику. Запускайте команды из каталога исходников:

```powershell
python -m unittest discover -p "test_*.py"
python -m PyInstaller --noconfirm --workpath build/app --distpath dist ats_monitor_ui.spec
python -m PyInstaller --noconfirm --workpath build/updater --distpath dist-updater updater.spec
```

Поместите dist-updater/updater.exe рядом с dist/ats_monitor_ui/ats_monitor_ui.exe, добавьте этот документ и образец конфигурации. Проверяйте запуск EXE до упаковки. Не включайте локальные JSON-конфигурации, пароли, ключи, журналы и резервные копии в ZIP.
